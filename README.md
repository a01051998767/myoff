# 마이오프 쉬는시간

구글 캘린더에서 **엄지·도연** 일정을 읽어 와, 둘이 **같이 쉬는 시간**과 한국 공휴일을 달력으로 보여주는 웹앱 (PWA, 파일 하나).

## 기능
- **달력**: 월별 보기, 좌우 스와이프로 달 이동. 열 때·달을 넘길 때·앱으로 돌아올 때 구글 캘린더에서 최신 일정을 다시 불러옴
  - 초록 칸 = 둘 다 그날 일정 없음 / 초록 칩 = 같이 비는 **4시간 이상** 구간 / 색 점 = 그 사람 일정 있음
  - **0시~9시는 계산에서 제외** (설정에서 변경 가능)
- **날짜 상세**: 엄지·도연·같이 타임라인, 같이 쉬는 시간, 각자 일정 목록
- **목록**: 이번 달 같이 쉬는 날 수, 빈 시간 목록, 공휴일
- **공휴일**: 구글 '대한민국의 휴일' 캘린더 + 앱 자체 계산(설·추석·대체공휴일) 병합

## 일정 판단 규칙
- 엄지·도연이 **별도 캘린더**면 그 캘린더를, 한 캘린더에 섞여 있으면 **제목에 이름이 들어간 일정**으로 구분 (설정에서 선택, 기본은 자동)
- 하루 종일 일정: 기본은 바쁨. 단, 제목에 `휴무, 휴가, 연차, 휴일, 쉬는날, 비번, off`가 있으면 쉬는 날로 봄
- 구글에서 '한가함(투명)'으로 표시한 일정, 거절한 일정은 무시

## 처음 설정 (한 번만)
구글 캘린더를 브라우저에서 직접 읽으려면 내 구글 클라우드 **OAuth 클라이언트 ID**가 필요합니다.
1. console.cloud.google.com → 새 프로젝트
2. API 및 서비스 → 라이브러리 → **Google Calendar API** 사용 설정
3. OAuth 동의 화면: 외부, **테스트 사용자**에 내 Gmail 추가
4. 사용자 인증 정보 → OAuth 클라이언트 ID → **웹 애플리케이션** → 승인된 JavaScript 원본에 `https://<아이디>.github.io` 추가
5. 앱 설정 탭에 클라이언트 ID 붙여넣기 → 구글로 로그인

권한은 **읽기 전용**(`calendar.readonly`)이고, 일정은 브라우저가 구글에서 직접 받아올 뿐 다른 곳으로 보내지 않습니다. 연결 전엔 설정 › 예시 데이터로 화면을 미리 볼 수 있어요.

## 아이폰에서 쓰기
1. GitHub 저장소 Settings → Pages → Branch 지정
2. 사파리로 `https://<아이디>.github.io/myoff/` 접속 → 공유 → **홈 화면에 추가**

## 참고
- 로그인 토큰은 약 1시간 유효해서, 만료되면 ↻(새로고침)을 눌러 다시 연결합니다.
- 앱 자체 공휴일 계산은 추정값이며, 임시공휴일은 구글 휴일 캘린더에서 가져옵니다.
