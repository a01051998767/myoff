# 마이오프 교대달력

설치 없이 폰 브라우저에서 쓰는 나만의 교대근무 달력 (PWA, 파일 하나짜리 웹앱).

## 기능
- **월 달력**: 내 근무 배지, 공휴일·대체휴일(자동), 음력 1·15일, 기념일, 월급날 강조, 메모 점, 근태·오버타임 표시, 월별 메모, 좌우 스와이프로 달 이동
- **조별 보기**: A~D조 전체 근무표, 내 조 강조
- **날짜 상세** (칸 누르기): 메모 / 근무 변경(본근무 표시·되돌리기) + 근태(연차 등) / 급여(오버타임 시간 → 자동 계산, 기타 급여)
- **통계**: 월 예상 급여, 근무 횟수, 근무시간, 근태 일수
- **설정**: 근무타입 편집(이름·색·모양·시간·수당·순서), 교대 패턴(순서·기준일·조 이름·조 간격·내 조), 오버타임 시급, 월급날, 기념일, 백업/복원

## 아이폰에서 쓰기
1. GitHub 저장소 Settings → Pages → Branch 를 이 브랜치(또는 main)로 지정
2. 사파리로 `https://<아이디>.github.io/myoff/` 접속 → 공유 → **홈 화면에 추가**

데이터는 그 기기 브라우저(localStorage)에만 저장됩니다. 폰을 바꿀 땐 설정 › 백업을 쓰세요.

## 참고
- 공휴일·대체휴일·음력은 브라우저 내장 음력(중국력 기반)으로 계산한 **추정값**입니다. 임시공휴일(선거일 등)은 설정 › 기념일에 `YYYY-MM-DD` + 빨간날로 추가하세요.
